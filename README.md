# TP1 – Programme Python

## 1. Présentation du programme

Ce projet a été réalisé dans le cadre du TP1 de programmation Python.

L'objectif est de réaliser plusieurs exercices pour apprendre les bases du langage Python.

Le programme principal est `main.py`.

## 2. Évolution du programme

- **Version 1 :** Création du programme et réalisation des premiers exercices.
- **Version 2 :** Ajout de nouvelles fonctionnalités.
- **Version 3 :** Amélioration du code et correction des erreurs.
- **Version 4 :** Finalisation du programme et vérification de son fonctionnement.

## 3. Utilisation du programme

Pour exécuter le programme :

1. Ouvrir le dossier `TP_Git_Python` dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File**.
4. Saisir les informations demandées dans le terminal.
5. Lire les résultats affichés.

## 4. Commandes Git utilisées

- `git init` : Initialiser un dépôt Git.
- `git add` : Ajouter les fichiers.
- `git commit` : Enregistrer les modifications.
- `git push` : Envoyer les fichiers vers GitHub.
- `git pull` : Récupérer les modifications depuis GitHub.
